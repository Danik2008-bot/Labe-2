\# Лабораторная работа 2. Cat and Mouse



Консольная игра «Кошка и мышь» на кольцевом поле.



\## Как работает

Программа читает файл команд (размер поля, ходы `M` и `C`, печать `P`), двигает игроков и записывает лог погони.



\## Запуск

dotnet run



Без аргументов программа проверяет три теста из папки data.
